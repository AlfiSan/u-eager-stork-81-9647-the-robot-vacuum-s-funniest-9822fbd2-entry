`main.ts` writes the line to `/output/entry.txt`:

> The rug and I have an agreement: I don't touch its fringe, it doesn't tell you about the crumbs.

Run it with Node 22.18+ (`node main.ts`). The entry is free, and the funniest line takes the $2 reward.
